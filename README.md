# 📖 Sobre o projeto

O **Portfólio Pessoal** é o meu cartão de visitas digital. Ele foi criado para reunir em um só lugar todas as minhas informações profissionais, facilitando o acesso de recrutadores, parceiros de tecnologia e entusiastas do código ao meu trabalho.

A interface foi pensada para ser limpa, responsiva e direta ao ponto, utilizando as melhores práticas de desenvolvimento web para garantir acessibilidade e boa performance.

---

# ✨ Funcionalidades

- **Apresentação Pessoal:** Seção "Sobre mim" detalhando minha jornada e stack tecnológica.
- **Galeria de Projetos:** Exibição interativa dos meus principais repositórios (como a *Agenda de Clientes*, *Loja de Informática*, entre outros), com links para o código e deploy.
- **Habilidades (Skills):** Demonstração visual das tecnologias e ferramentas que domino.
- **Contato:** Links diretos para meu LinkedIn, GitHub e E-mail.
- **Design Responsivo:** Layout adaptável para qualquer tamanho de tela (mobile, tablet e desktop).
